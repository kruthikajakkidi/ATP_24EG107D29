## Week-1 Assignments

### Overview:
This week includes basic JavaScript programs covering conditionals,\
  loops, functions, arrays, searching, and object manipulation.
  
### Definitions:
#### Conditional Statements:
Used to perform different actions based on different conditions (e.g., if, else, ternary operator).
#### Loops:
Used to execute a block of code repeatedly until a condition is met (e.g., for, while loops).
#### Functions:
Reusable blocks of code designed to perform a specific task.
#### Arrays:
Data structures that store multiple values in a single variable.
#### Searching:
The process of finding a specific element in a data structure like an array (e.g., linear search).
#### Object Manipulation:
Working with JavaScript objects by adding, removing, or updating properties.
#### Splice() Method:
An array method used to add, remove, or replace elements in an array.
