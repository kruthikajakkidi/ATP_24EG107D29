## Week-5 Assignments
### Overview:

-This week includes CSS layouts using Flexbox and Grid, responsive web design, HTML tables, and React applications with reusable components and Tailwind CSS.

### TASKS:
1. HTML Tables:\
Built score and user tables using colspan and rowspan\
Applied alternating row colors using nth-child()
2. Best City Guide Page:
Designed a multi-section webpage using Flexbox\
Styled navigation and horizontal content layout
3. Hello World Layout:
Created responsive webpage sections using Flexbox\
Styled navbar, buttons, content, and footer
4. Responsive Grid Layout:
Built responsive CSS Grid with multiple breakpoints\
Used media queries for tablet and mobile layouts
5. Flexbox Card Layout:
Created card-based layout using Flexbox\
Styled profile cards with shadows and circular images
6. React Product Listing App:
Displayed products using reusable React components\
Used Tailwind CSS responsive grid classes
7. React User Directory App:
Rendered user cards dynamically using .map()\
Added Navbar and responsive Tailwind styling
8. Counter Component:
Built counter using React useState hook\
Added increment and decrement functionality

### Features Used:
HTML Tables (colspan, rowspan)\
