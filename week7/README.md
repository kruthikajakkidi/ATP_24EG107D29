📖 My Blog Application – Capstone Project

A full-stack blogging platform built using the MERN stack with 
role-based authentication for Users, Authors, and Admins.

✨ Features:
- Secure JWT authentication & authorization
- Authors can create, edit, delete, and publish articles
- Users can read blogs, comment, and manage profiles
- Profile image upload using Cloudinary
- Admin dashboard to manage users and activate/deactivate accounts
- Separate dashboards for each role

🧰 Technologies Used:
- JWT Authentication
- Cloudinary (media storage & image uploads)
- Role-Based Access Control (RBAC)
- Zustand (global state management)

💻 Tech Stack:
Frontend:
  React.js, Tailwind CSS, Zustand

Backend:
  Node.js, Express.js

Database:
  MongoDB

🚀 Deployment:
- Frontend → Vercel
- Backend → Render

🎯 Highlights:
- Built a multi-role authentication system (User/Author/Admin) 
  with JWT and route-level access control
- Developed a full article lifecycle — creation, editing, 
  publishing, and deletion — with Cloudinary-backed media uploads
- Implemented an Admin dashboard with user management and 
  account moderation (block/unblock)
