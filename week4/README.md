## WEEK-4 Assignment – Basic Web Pages
### Overview:
This assignment includes basic HTML structure, text formatting, lists, images, and links using simple web pages.

### Definitions:
#### HTML:

HyperText Markup Language used to create and structure web pages.

#### Web Page:

A document displayed in a web browser containing text, images, links, and other elements.

#### Headings:

HTML tags (h1 to h6) used to define titles and section headings on a webpage.

#### Paragraphs:

HTML <p> tag used to display blocks of text content.


#### Navigation Links:

Links used to move between webpages or sections of a website.

#### External Link:

A hyperlink that redirects users to another website.

#### Page Linking:

Connecting multiple HTML pages using hyperlinks.

#### Live Server:

VS Code extension used to run and preview web pages in a browser.

#### Browser:

Software application used to access and display web pages.

#### VS Code:

Source-code editor used for writing and managing HTML files.
