Employee Management System

A full-stack MERN application to manage employee records with complete CRUD operations.
The project includes a backend API for handling employee data and a responsive frontend to add, update, delete, and view employee details.

✨ Features
Add new employees
View all employee details
Update employee information
Delete employee records
REST API integration
Responsive UI

💻 Tech Stack
Frontend: React.js, Tailwind CSS, Zustand
Backend: Node.js, Express.js
Database: MongoDB

🚀 Deployment
Frontend → Vercel
Backend → Render
